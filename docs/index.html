01ALREADY RUNNING LYRICFLASH

Update over Wi-Fi

No cable needed. Open the device's web page (its address is in Settings → Device Settings on the device), go to Firmware and install the newest version. Saved Wi-Fi and settings are kept.

This is the normal way to update.

02INSTALL OVER USB

Connect by USB

Use desktop Chrome or Edge and a USB data cable. If the device is not detected, hold BOOT, press RESET, then release BOOT.

USB install unlocks once the published firmware has been checked.
USB install needs a computer with desktop Chrome or Edge. On a phone, use Update over Wi-Fi above, or open this page on a computer.

03FIRST-TIME SETUP

Connect it to your Wi-Fi

After a new install the device starts its own open Wi-Fi network called LyricFlash-Setup. Join it from your phone or computer and the setup page opens by itself (or go to http://192.168.4.1). Choose your home Wi-Fi there.

For Song ID, add your AudD API key on the device's web page. Pressing Play without Wi-Fi or a key shows a red reminder under the Play button.
