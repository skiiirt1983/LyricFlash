02INSTALL TO DEVICE

Update an existing LyricFlash device

Connect by USB in desktop Chrome or Edge. Choose the option to KEEP existing data if asked. Do not select Erase. This updater only writes the app and OTA selector, but a browser tool can still erase the device first if authorized. If it does not offer a keep-data option, cancel. Use only on an existing LyricFlash device.

This browser does not support Web Serial. Use a compatible desktop Chrome or Edge.USB flashing requires a secure HTTPS context.
Firmware installation locked until the full image has been validated and published.

This method retains Wi-Fi only if the device already has the credentials stored. It cannot restore credentials erased by an earlier full installation.

Complete USB recovery — resets saved settings

Use only when the existing-device updater cannot recover the unit, or installing LyricFlash from factory firmware. This full image overwrites stored Wi-Fi.

Chrome/Edge desktop required.
03OPTIONAL LOCAL FILE

Install a full USB firmware file from your computer

Already downloaded an Alpha / Beta release? Choose lyricflash-full.bin below. The file stays on your computer; the browser checks its ESP32-S3 bootloader, LyricFlash application and partition layout before enabling the simple USB installer.

Choose a complete USB firmware .bin to enable installation.
USB installation is unavailable in this browser. Try desktop Chrome or Edge. USB installation requires an HTTPS connection.

Alternative: ESPHome Web lets you Connect, choose Install, and select the same full .bin file with no advanced flash settings.

This writes the selected full USB image at address 0x0. Saved Wi-Fi and device settings may be reset. Do not choose an application-only OTA .bin. You will be asked to select the device's USB/COM port.
